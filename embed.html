Как ассистент подключён к этому сайту

Этот сайт — пример стороннего сайта. Ассистент AI-Dana встроен в него так же, как его встроит любая компания: без сборки, без своего сервера и без обновлений вручную.

Две строки в HTML

Перед закрывающим </body>:

<script src="https://cdn.jsdelivr.net/npm/@dsrcjs/ai-widget@1/dist/ai-dana-chat.js" defer></script>
<ai-dana-chat launcher></ai-dana-chat>

Внизу справа появляется кнопка чата. Адрес бэкенда AI-Dana уже зашит в виджет, React и другие библиотеки сайту не нужны: всё внутри одного файла, стили изолированы и не ломают вёрстку сайта.

Обновления приходят сами

@1 в адресе — это всегда последняя версия виджета. Новый релиз доходит до сайта за несколько минут, сайту ничего менять не нужно. Кто хочет зафиксировать версию, указывает её точно: @dsrcjs/ai-widget@1.0.7.

Что можно настроить

  • lang="kk|ru|en" — язык ассистента (на этом сайте его переключают кнопки KZ / RU / EN).
  • theme="light|dark|auto" — тема, position="bottom-left" — угол экрана.
  • site-key="…" — ключ сайта. Без ключа работает общий бесплатный тариф. С ключом — свои цвета, логотип, приветствие, режимы и лимиты, и чат принимается только с доменов этого сайта. Ключ выдаёт AI-Dana.
  • Методы элемента: open(), close(), setLang(), setTheme().

Если на сайте настроен CSP

Виджету нужно разрешить:

script-src  https://cdn.jsdelivr.net
connect-src https://dev-ai.kgd.gov.kz
img-src     https://dev-ai.kgd.gov.kz blob: data:
style-src   'unsafe-inline'

Этот сайт сам работает с такой политикой: она задана в его <head>.

Через npm

Для сайтов со сборкой (React, Vue и т. п.) есть пакет:

npm i @dsrcjs/ai-widget

import { mountLauncher } from '@dsrcjs/ai-widget';
mountLauncher({ lang: 'ru' });

Так виджет обновляется только вместе со сборкой сайта.
