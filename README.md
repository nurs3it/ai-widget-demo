# Нота Есеп — демо-сайт виджета AI-Dana

Сайт вымышленной бухгалтерской компании. Ассистент AI-Dana встроен в него так, как его встроит любой сторонний сайт:
две строки в HTML, без сборки и без своего сервера.

```html
<script src="https://cdn.jsdelivr.net/npm/@dsrcjs/ai-widget@1/dist/ai-dana-chat.js" defer></script>
<ai-dana-chat launcher></ai-dana-chat>
```

- `index.html` — главная страница сайта;
- `embed.html` — страница для коллег: как подключён ассистент, что можно настроить, что нужно в CSP;
- `site.js` — кнопки сайта («Спросить ассистента», KZ / RU / EN) через API виджета (`open()`, `setLang()`).

`@1` — всегда последняя версия виджета: после релиза сайт получает её за несколько минут, ничего менять не нужно.

## Деплой на Vercel

Import Project → этот репозиторий → Framework Preset: **Other**, Build Command пустой, Output Directory `.`.
Это статика, сборки нет.

## Проверка на другом бэкенде

Адрес бэкенда зашит в виджет (`https://dev-ai.kgd.gov.kz`). Для проверки без релиза — параметры адреса:

- `?api=http://localhost:8080` — локальный стек (принимается только `localhost` / `127.0.0.1`, иначе ссылкой с
  `?api=` можно было бы увести вопросы посетителей на чужой сервер);
- `?key=<ключ>` — ключ сайта из админки AI-Dana (без него — общий анонимный тариф).

## Локально

```bash
python3 -m http.server 4173
```

Открыть http://localhost:4173.
